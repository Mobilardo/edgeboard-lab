# EdgeBoard Lab

EdgeBoard Lab - браузерный генератор торцевых разделочных досок, который начинает проектирование с реальных ограничений мастерской. Пользователь задаёт размеры заготовки, пропил, доступную ширину склейки, длину струбцин и безопасную ширину ламели; приложение строит воспроизводимый узор и сразу выдаёт технологический маршрут.

## Возможности

- восемь семейств узоров с детерминированной генерацией по ключ генерации;
- интерактивная 3D-модель доски: можно тянуть мышью, менять угол и видеть толщину;
- проверка размеров доски относительно оборудования;
- компиляция узора в панели, ламели, поперечные срезы и карту разворотов;
- оценка расхода, потерь на пропил и ориентировочной стоимости;
- риск-скор 0-100 с конкретными причинами и способами снизить риск;
- кнопка безопасной переработки проекта;
- три проектных листа на экране: чертёж, закупка/раскрой, сборка;
- печатный лист мастера с картой, порядком резов и чек-листом сухой сборки.

Все вычисления выполняются локально. Сервер и учётная запись не нужны.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm test
npm run build
```

## Архитектура

Чистое вычислительное ядро находится в `src/core/` и экспортируется через `src/core.ts`. Оно не зависит от React и содержит ключ генерации-RNG, генераторы семейств узоров, производственный компилятор, оценку материалов и анализ рисков. Интерфейс в `src/App.tsx` только управляет параметрами и отображает готовый `BoardPlan`.

Алгоритмы намеренно прозрачны и приближённы. Итоговый талон - инструмент планирования, а не замена проверке реальной влажности древесины, геометрии станка и инструкции к оборудованию.

## Публикация

Vite настроен с базовым путём `/edgeboard-lab/`. рабочий процесс в `.github/workflows/deploy.yml` собирает и публикует `dist` в GitHub Pages.
